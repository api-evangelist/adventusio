Adventus.io operates an international student recruitment marketplace connecting
education institutions, recruitment agents and students. Recruiters manage student
records, documents, academic achievements, applications and orders in one place;
institutions publish courses and intakes and receive applications back.

## What an agent can and cannot do here

- There is a real, machine-readable contract: a GraphQL API at
  https://api.adventus.io/graphql with 47 queries and 30 mutations across 99 types.
  Introspection answers anonymously, so the full schema is retrievable with no
  credentials.
- There is NO developer portal, NO getting-started guide, NO API reference, NO SDK,
  NO CLI, NO sandbox and NO published rate limits. Credentials are issued with a
  partner account, not self-serve.
- Reference data (countries, languages, studyLevels, gradingSystems) answers
  anonymously. Everything about students, orders, institutions, documents and
  messaging returns a GraphQL error with extensions.code UNAUTHENTICATED until a
  bearer token from the userLogin or studentLogin mutation is supplied.
- Writes are NOT safely retryable. No mutation supports an idempotency key. Only
  one write (intake_control_createSchedule) has a reversal operation
  (intake_control_cancelSchedule), and no reversal window is stated anywhere.

## API

- [GraphQL endpoint](https://api.adventus.io/graphql): the single API surface.
  POST only; GET returns 400. Errors arrive as HTTP 200 with errors[].
